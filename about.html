{ About } _

Exposing what was meant to stay invisible.

Security researcher specialising in web and API security, with a focus on authentication, authorisation, and tenant-isolation flaws in multi-tenant SaaS systems. I find the design-level vulnerabilities scanners miss and write reproducible reports with concrete remediation guidance.

I am Ali Taher — known online as lool0x01. I started security research in 2024, and since then I have had 50+ valid vulnerabilities responsibly reported through HackerOne and YesWeHack.

Most of that work sits where product design meets access control: an identifier that is trusted because it looks opaque, a background job that forgets to carry the tenant scope, an admin route that is hidden in the UI but not in the router. Those flaws rarely show up in a scanner's output, which is why the method is manual, hypothesis-driven, and anchored to a threat model rather than a payload list.

I believe in responsible disclosure. Every report I send is written to be reproduced: preconditions, numbered steps, the exact request and response, the impact in business terms, and a remediation the engineering team can actually ship. If a finding cannot be proven, it is not reported.

Between engagements I research new attack vectors — mostly in authentication, session handling and multi-tenant isolation — and turn the ones that generalise into notes and tooling I can reuse.

{ What I do } _

My work: skills, certifications, tools, and what I bring to the table.

01

Web App Pentesting

Manual, hypothesis-driven testing of the application itself — authentication, session handling, access control, injection and business logic. The threat model comes first, so testing follows the money and the tenant boundary instead of a scanner's checklist.

ManualThreat modelOWASP
02

API Security Testing

REST and GraphQL endpoints mapped from the client bundle, then attacked: object-level authorisation, field-level authorisation, mass assignment, version drift and rate limits — including the fields the interface never shows but the API still returns.

RESTGraphQLBOLA / BFLA
03

Bug Bounty Hunting

Careful, in-scope research on HackerOne and YesWeHack. Each report is a reproduction path: preconditions, numbered steps, request and response evidence, impact, and a fix the engineering team can act on.

In scopeReproducibleTriaged
04

Authentication & Session Testing

Login, password reset, MFA, OAuth and SSO flows tested end to end. The interesting cases are usually the second factor that is never checked on one endpoint, the reset token that survives a password change, or the session that is never invalidated.

MFAOAuth / SSOSession life cycle

Recon & Asset Discovery

Subdomain and asset enumeration, archive mining, JavaScript analysis and content discovery — used to find the forgotten host that skips the gateway the rest of the estate goes through.

Security Reporting
